Ethics & Attribution

This page documents the basic ethical and privacy practices used in this project.

Copyright & Asset Licensing

This website uses original HTML, CSS, and JavaScript created for this project. No third-party images, icons, or external fonts are required. This helps avoid unnecessary licensing issues and keeps the website lightweight.

  • Images: The site uses creator personal image, other than that there's no third party image used.
  • Fonts: The site uses standard system fonts.
  • Icons: This website uses free icons from Font Awesome for navigation and interface elements, including the Home, Ethics, and Contact icons.
  • Stylesheets: The CSS was created for this project.
  • Attribution: No third-party media requires attribution in the current version.

Privacy Statement

This website does not intentionally collect, store, or track personal information. It does not use analytics, advertising trackers, or cookies in this project.

The contact form is a demonstration interface only. It does not send or save messages to a server.

Accessibility & Inclusivity

The site uses semantic HTML, descriptive page titles, visible focus states, keyboard-friendly links and buttons, responsive layouts, and readable contrast.

Examples of descriptive alternatives include:

  • The profile card is given an accessible label describing its purpose.
  • The navigation and menu button have accessible labels so screen-reader users can understand their function.

Security & Netiquette

When deployed, this project should be hosted over HTTPS. The public repository should not contain passwords, API keys, private documents, or other sensitive information. Online communication should remain respectful and responsible.
